## Default Functionality
SpectralBot ``!force`` command default to only allow my User ID as the person running the command. Please change the OWNER_ID variable to set it to your own. Usage of !force commands are specified in the license.

## Dependencies
Dependencies:
* Node.js
* Discord.js

### All other dependencies are specified by Node.JS when you attempt to ``node {scriptname}`` the file. You must install them via ```npm install```.
